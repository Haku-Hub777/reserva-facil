# Reserva Fácil

Prototipo de Gerencia de Software para la recepción de un hotel pequeño. Consulta habitaciones por fechas, registra reservas sin cruces, permite encontrarlas y conserva las cancelaciones.

## Descargar y ejecutar

Descarga `Reserva_Facil_Proyecto_y_Evidencias.zip`, extrae la carpeta `Reserva_Facil` y ábrela en PowerShell. Ejecuta `py -3 server.py --demo` y abre [la aplicación local](http://127.0.0.1:8000). El ZIP incluye los archivos fuente, la guía, las pruebas, los burndowns y las dos retrospectivas.

## Historial original

El archivo `reserva-facil.bundle` guarda los siete commits originales y la etiqueta `v1.0.0`. Descárgalo y ejecuta:

```powershell
git clone reserva-facil.bundle reserva-facil-original
cd reserva-facil-original
git log --oneline
```

La rama de publicación de GitHub registra la carga del paquete. El historial de origen del desarrollo está en el archivo Git portable.
